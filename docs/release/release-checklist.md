# 发布清单（Release Checklist）

> 角色：release-ops-lead ｜ 覆盖：发布前检查 / Changelog 模板 / 回滚方案 / 本地化。

## 1. 发布前检查项（Pre-Release Gate）

| 类别 | 检查项 | 通过标准 | 负责人 |
|---|---|---|---|
| 构建 | 版本号/构建签名 | 与 manifest 一致 | 技术 |
| 构建 | 崩溃率 | 内部验收 < 0.5%，Demo < 1% | quality-lead |
| 功能 | 全核心循环可通 | 带入→撤离→带出无阻断 | QA |
| 功能 | 存档/云存档 | 读写、跨会话稳定 | 技术 |
| 性能 | 帧率/内存 | 达标最低配置，无泄漏 | 技术 |
| 合规 | 评级(ESRB/PEGI) | 已提交/获批 | release-ops |
| 商店 | 商店页/价格/区服 | 审核通过、可见 | release-ops |
| 运营 | 热修/回滚流水线 | 演练通过 | 技术 |
| 反馈 | 游戏内入口+崩溃上报 | 已联调上线 | release-ops |
| 本地化 | 首发语言覆盖 | 见 §4 | 本地化 |

**Exit Gate**：以上全绿 + 主理人签字，方可推送。

```markdown
# vX.Y.Z — <版本名/代号>
发布日期：YYYY-MM-DD ｜ 类型：热修 / 内容补丁 / 大版本

## 新增
- 

## 调整（平衡/体验）
- 

## 修复
- [P0] 
- [P1] 

## 已知问题
- 

## 反馈来源致谢
- 来自 Discord/Steam：<条目摘要>
```

规则：P0/P1 必须标注来源闭环；已知问题透明列出，降低差评。

## 3. 回滚方案（Rollback）

| 场景 | 触发条件 | 动作 | 时效 |
|---|---|---|---|
| 构建级故障 | 启动崩溃/存档损坏 | Steam 回退上一构建 + 公告 | < 2h |
| 严重平衡崩坏 | 大量 P0 反馈/数据异常 | 热修或配置回滚(关服热更) | < 4h |
| 数据安全事故 | 丢失/泄露 | 停服 + 技术介入 + 通报 | 即时 |

**前置**：每版保留上一稳定构建；配置类(数值/掉落)支持不停服热更；回滚后 24h 内补发复盘。

## 4. 本地化覆盖（语言优先级）

| 优先级 | 语言 | 说明 | 首发建议 |
|---|---|---|---|
| P0 | 简体中文 | 核心市场 + IP 母语 | ✅ 必带 |
| P0 | 英文(EN) | Steam 全球基本盘 | ✅ 必带 |
| P1 | 日文(JA) | 弹幕游戏重镇 | 建议首发/Early EA |
| P1 | 繁体中文 | 港澳台 | 建议首发 |
| P2 | 韩文(KO) | 东亚市场 | EA 阶段 |
| P2 | 德/法/西(EU) | 欧美长尾 | EA 阶段 |
| P3 | 其他 | 社区驱动 | 后续 |

**原则**：UI/商店页/核心文案先本地化；语音(影视 IP 调性)可后续；避免机翻，关键市场用母语校对。
