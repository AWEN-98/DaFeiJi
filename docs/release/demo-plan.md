# Demo 发布节奏（Release-Ops Plan）

> 角色：release-ops-lead ｜ 平台：PC/Steam 首发 ｜ 美术：卡通渲染
> 品类：弹幕(shmup) + 肉鸽(随机强化) + 合成(merge) + 搜打撤(extraction)
> 原则：lean，里程碑用相对周数，内容范围以"最小可验证核心循环"为底线，避免过早透支。

## 1. 里程碑与时间盒

> 时间以"垂直切片完成"为 W0 基准；周数为目标区间，非承诺排期。每阶段设硬退出标准(Exit Gate)。

| 阶段 | 相对周 | 目标产出 | 退出标准(Exit Gate) | 受众 |
|---|---|---|---|---|
| 垂直切片 Vertical Slice | W0–W6 | 1 张地图 + 1 机体 + 1 Boss，打通"带入→搜→战→强化→合成→撤离→带出"全循环 | 单局 8–12 分钟可玩、无致命 bug、循环闭环可验证 | 内部 / 主理人评审 |
| 封闭 Alpha Closed Alpha | W7–W14 | 3 机体 + 2 地图 + 2 Boss + 元进度骨架；合成/强化随机池成型 | 核心循环留存信号（次日/三日留存可达标）、风险博弈成立 | 受邀玩家(50–200) |
| Demo（Steam Next Fest） | W15–W20 | 公开试玩，含教学、wishlist 锚点、留存钩子 | 试玩转化 wishlist 达标、崩溃率 < 1% | 全体 Steam 用户 |
| 抢先体验 EA | W21–W32+ | 内容扩展、稳定性、社区运营基线 | 商店页转化与评测正向、热修流水线就绪 | 全体付费用户 |

**节奏关键约束**
- Demo 不开放完整元进度存档继承到 EA（避免承诺负担）；可保留"试玩成就/徽章"作为轻量钩子。
- 每个 Exit Gate 由 release-ops-lead 与主理人共同签字，未过闸不进下一阶段。

## 2. Demo 内容范围

> 目标：用最小内容验证四大支柱（高重复可玩 / 强成长反馈 / 风险博弈 / 组合深度），同时保留"内容蓄水池"供 EA 释放。

| 维度 | Demo 包含（最小闭环） | 刻意保留到 EA（不透支） |
|---|---|---|
| 机体 | 2–3 架，差异化弹幕风格 | 其余机体、皮肤线 |
| 地图 | 1 张主地图 + 1 个撤离点变体 | 多地图生态、动态天气 |
| Boss | 1 个山海经系 Boss（影视 IP 调性） | Boss 轮换池、周本 |
| 核心循环 | 带入→搜资源→弹幕战→随机强化→合成→撤离/带出 | 深度 meta 科技树 |
| 强化/合成 | 随机强化池(小) + 2 档合成 | 大型合成树、词条系统 |
| 风险博弈 | 带入资源可损 + 撤离成功带出 | 保险/合约等高级博弈 |
| 教学 | 交互式引导首局 | 进阶技巧教学 |

**留存钩子（Demo 内置，低成本）**
- 单局短（8–12 分钟），天然适配"再来一局"。
- 撤离成功的"带出清单"结算页 + 随机强化 reveal，制造正反馈峰值。
- 山海经 Boss 背景卡（影视 IP 叙事碎片），撩动 IP 粉丝与世界观好奇。
- Next Fest 限定：试玩成就 / 装饰性徽章，wishlist 后解锁EA 抢先特权提示。

**内容透支红线（禁止在 Demo 做）**
- 不开放完整剧情战役；不承诺 EA 存档继承；不堆数值深度导致平衡难回滚。

## 3. 平台策略（Steam 首发）

### 3.1 商店页基线（Alpha 阶段即上线）
| 动作 | 时机 | 负责人 | 说明 |
|---|---|---|---|
| 商店页 + 预告片 v1 | Closed Alpha 启动 | release-ops + 市场 | 立 wishlist 锚点，早积累 |
| 胶囊图/标签/简介 | 持续迭代 | 市场 | 突出"弹幕+搜打撤"差异点 |
| 系统需求页 | Demo 前 4 周 | 技术 | 明确 PC 配置，降低差评风险 |

### 3.2 Steam Next Fest（Demo 主战场）
| 动作 | 说明 |
|---|---|
| Demo 上架 + 限时试玩 | 配合 Next Fest 档期，集中流量 |
| 直播/开发日志 | 主理人出镜讲"融合品类"设计，强化 IP 与团队人设 |
| 试玩内 wishlist 弹窗 | 首局结束/撤离成功页轻提示，转化峰值 |
| 媒体/创作者 seeding | 提前 2 周寄 demo key 给中式志怪/弹幕游戏 KOL |

### 3.3 Wishlist 增长动作
| 渠道 | 动作 | 频率 |
|---|---|---|
| Discord | 开发日志、投票、玩家共创山海经怪物 | 周更 |
| 短视频平台 | 弹幕爽点剪辑 + Boss 设计幕后 | 每周 2–3 |
| Steam 公告 | 里程碑/Next Fest/EA 倒计时 | 节点驱动 |
| KOL/媒体 | 深度评测、融合品类定位稿 | 节点驱动 |

**北极星指标**：Next Fest 期间 wishlist 增量 vs 目标；Demo 崩溃率/差评率作为发布健康度红线。
