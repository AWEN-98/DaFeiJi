# 玩法借鉴优化：土豆兄弟（Brotato）+ 吸血鬼幸存者（Vampire Survivors）

> 目标：把这两款标杆级「自动射击 + 肉鸽成长」游戏的核心爽点，嫁接到《虚空残余：地块协议》的「打飞机 + 肉鸽 + 合成 + 搜打撤」框架里，解决当前「玩法骨架完整，但成长曲线和自动火力爽感不足」的问题。

---

## 一、两款参考游戏的核心循环

| 游戏 | 核心循环 | 最爽的点 | 最适合我们学什么 |
|------|----------|----------|------------------|
| **土豆兄弟（Brotato）** | 20 秒一波敌人 → 存活后进入商店 → 用本局货币买武器/堆属性 → 下一波更难。 | ① 自动武器越来越多，屏幕越来越热闹；② 属性 build 有明显方向（堆攻速/堆生命/堆暴击）；③ 波次-商店节奏像心跳。 | **常驻自动副武器** + **属性 build 协同** + **局内商店/波次补给** |
| **吸血鬼幸存者（Vampire Survivors）** | 敌人无限涌来 → 击杀掉落经验宝石 → 走动吸取 → 升级触发「三选一」→ 选新武器/升级武器/被动 → 后期满屏子弹。 | ① 「移动才能吃到经验」制造走位张力；② 升级三选一给玩家明确的「这一局我要走什么流派」；③ 武器+被动组合「进化」成终极形态。 | **经验宝石 + 等级 + 升级三选一** + **武器进化/合成** |

## 二、我们已有什么、还缺什么

### 已经有的（基础很扎实）
- **打飞机手感**：手动瞄准、机体差异化（青龙/赤鸾/玄武/白泽）。
- **肉鸽符文**：击杀累计 → 三选一，28 枚符文 + 5 系羁绊 + 交叉羁绊。
- **自动炮台**：援护符·水可以召唤环绕炮台，但**只是符文奖励之一**，不是常驻。
- **局内合成/撤离**：2 合 1 / 3 合 1、搜刮节点、限时撤离，搜打撤闭环成立。
- **裂隙 / Boss / 相位潮汐**：局内变数已经不少。

### 缺的（导致「不够完善」）
1. **没有清晰的经验曲线**：符文触发靠「击杀计数」，玩家看不到「再差多少升级」，少了 VS 那种「还差一口经验」的走位冲动。
2. **没有常驻自动火力**：大部分时间只有手动主武器在打，屏幕不够热闹，肉鸽「变强」的反馈弱。
3. **升级奖励里缺少「武器升级」选项**：现在的三选一全是符文/属性，缺了 VS/Brotato 那种「获得/强化一把自动武器」的兴奋点。
4. **没有武器进化 / build 角色方向**：合成只是升阶数值，没有「A 武器 + B 被动 = 质变新形态」的惊喜。
5. **没有局内商店 / 波次补给**：搜打撤的灵玉只能带出去，不能在局内花掉做 immediate 决策。

## 三、本期已落地的借鉴（原型已实装）

### 1. 灵蕴 / 经验 / 等级系统（VS 核心）
- 击杀敌人现在掉落**灵蕴宝石**（金色小光球）。
- 玩家飞过去（或磁力符）吸取，累积经验。
- 经验满后升级，触发**三选一**（复用原有的符文弹层，但触发源改为等级）。
- HUD 左下角新增 **Lv + 经验条**，右上角状态板同步显示「Lv X · 经验 X/X」。

> 这就是 VS 的灵魂：玩家为了吃到经验必须移动，走位因此有了意义。

### 2. 常驻自动法球 + 战技升级（Brotato/VS 自动武器）
- 玩家出生就自带 **1 枚环绕法球**，自动索敌射击（复用原有无人机代码）。
- 升级三选一里新增 3 项**战技**选项：
  - **环列法球**：再召唤 1 枚法球（上限 6）。
  - **法球共鸣**：法球伤害 +40%。
  - **法球疾转**：法球射速 +30%。
- 法球数量和强度成为本局 build 的一条明确支线。

> 这是 Brotato 的「自动武器堆叠」体验：越打屏幕越热闹，玩家同时享受手动瞄准和自动火力覆盖。

### 3. 三选一池扩大为「符文 + 战技」
- 原来的 28 枚符文 + 新增 3 项战技，合并成统一的升级池。
- 卡牌 UI 已适配：战技无系别，显示为「✦ 战技」，羁绊提示改为「常驻副武器」。

## 五、下一步可继续借鉴（按优先级）

| 优先级 | 内容 | 对应参考 | 预计效果 |
|--------|------|----------|----------|
| **P1** | **武器进化/合成**：某把武器升到满级 + 持有特定符文被动 → 触发「进化」成终极形态（参考 VS 的武器 + 被动 = 终极）。 | VS | 把现有「合成升阶」做成有惊喜感的质变。 |
| **P2** | **局内空域补给站**：消耗局内灵玉购买一次性强化 / 临时武器 / 属性。 | Brotato 波次商店 | 让局内经济也有即时决策。 |
| **P3** | **驾驶员/流派选择**：出击前选一个 build 方向（如「法球专精」「暴击流」「龟壳流」），影响掉落倾向和初始属性。 | Brotato 角色 | 每局开局就有明确目标。 |
| **P4** | **Brotato 式波次节奏**：把一局切分为若干 30~45 秒波次，波间给短暂补给/休整窗口。 | Brotato | 强化「存活 → 奖励 → 更难」的心跳感。 |
| **P5** | **经验宝石与相位潮汐联动**：余烬相经验掉落 ×2（已在代码里做了基础兼容）。 | VS × 我们已有机制 | 鼓励玩家在余烬期冒险刷经验。 |

---

## 六、一句话总结

> 本期先借了 **VS 的经验等级三选一** 和 **Brotato/VS 的常驻自动副武器** 这两条最直接、最认得出的机制，把「打飞机」的成长曲线和屏幕爽感先立起来；下一步可以继续做 **武器进化** 和 **局内商店/流派选择**，让搜打撤的中间决策更密、更肉鸽。
