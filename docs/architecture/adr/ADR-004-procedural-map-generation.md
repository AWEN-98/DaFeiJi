# ADR-004 程序化地图生成（Procedural Map Generation）

> 状态：**已决策** ｜ 关联：ADR-002（确定性/种子）、core-loop.md、concept-doc（P3 高重复可玩）

---

## 结论（Conclusion First）

采用**"手工模块 + 节点图生成器"混合 PCG（Hybrid PCG）**：

- 地图由**手工预制模块（Module）**拼接而成（房间/走廊/竞技场），保证美术与战斗手感；
- 一个**种子驱动的节点图生成器**决定模块选择、摆放、连接与内容填充；
- **关键锚点（撤离点 EXFIL、Boss 竞技场）强制为手工 set-piece**，保证可达性与体验底线；
- 全程**确定性**：同一 `seed` + 同参数 → 同一地图（QA P5）。

---

## 节点图模型（MapGraph）

| 节点类型 | 含义 | 生成规则 |
|---------|------|---------|
| `SPAWN` | 出生点 | 固定 1 个，手工锚 |
| `COMBAT` | 战斗房 | 权重随风险档提升 |
| `LOOT` | 资源/搜刮点 | 加权随机数量 |
| `EVENT` | 事件/精英 | 中低权重 |
| `HAZARD` | 陷阱/环境危害 | 随风险档提升 |
| `BOSS` | Boss 竞技场 | **手工 set-piece，固定 1 个** |
| `EXFIL` | 撤离点 | **手工 set-piece，保证从 SPAWN 可达** |

边（Edge）= 连通关系，由生成器按"树 + 少量环"布线，避免死路。

---

## 生成管线（四阶段，全部种子驱动）

```
1) Topology   : 生成 MapGraph（节点类型/数量/边），风险档调权重
2) Stitching  : 每节点按类型从 Module 目录抽选预制体，拼接锚点、生成走廊
3) Population : 敌人/掉落/Hazard 按 seeded 表填充（绑定 ADR-002 IRng）
4) Validation : BFS 校验 SPAWN→EXFIL 可达；不可达则重抽（同种子内重试，仍确定）
```

- 种子来源：`run.save.seed`（core-loop §2），支持"复现 Bug / 分享地图"。
- 风险档（地图选择时预览）→ 影响 COMBAT/HAZARD 权重与掉落 rarity 表。

---

## 手工 vs 程序化边界

| 项 | 手工（必做） | 程序化（生成） |
|----|------------|--------------|
| 模块几何/锚点 | ✅ 每个 Module 预制 | — |
| EXFIL / BOSS 位置 | ✅ set-piece | — |
| 模块选用/连接 | — | ✅ 生成器 |
| 敌群/掉落/Hazard 内容 | 配置表（手工） | ✅ 依种子实例化 |
| 难度/风险曲线 | 参数（手工） | ✅ 生成器消费 |

## 后果
- 复用美术手工资产 + 程序化重玩性，契合 P3"高重复可玩"。
- 可达性有保证（EXFIL 手工 + BFS 校验）→ 解 QA P2 Blocker。
- 负面：需建 Module 目录与内容表；缓解：垂直切片仅 1 张地图（少量模块），随内容扩展。
- 未决：是否暴露"种子分享/自定义种子"给玩家（影响 replay/速通）→ 留待 1.0。
