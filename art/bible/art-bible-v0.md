# ART BIBLE v0 — 视觉身份

> 项目：打飞机(shmup) × 肉鸽 × 合成 × 搜打撤(extraction)
> 平台：PC / Steam 首发　|　美术基调：卡通渲染(cartoon)　|　主题钩子：中式志怪 / 都市奇幻（山海经）
> 文档版本：v0（仅规格，不含成品美术）　|　评审标准：lean（多用表格，精炼）

---

## 0. 一句话定调（Design Spine）

**「霓虹山海」——用高饱和卡通笔触把中式志怪画进赛博都市的夜空，让弹幕在灯火与妖气之间保持极致可读性。**

搜打撤的张力通过**「可带出=亮金 / 将损失=暗红」**的色彩契约贯穿全程；肉鸽随机强化用**色温跃迁**表达稀有度；中式志怪不是恐怖，而是**怪趣、喜庆、带妖气的国潮**。

## 1. 基调与情绪（Tone & Mood）

| 维度 | 定义 |
|---|---|
| 情绪主调 | 紧张中带俏皮；高风险高收益的「赌命快感」 |
| 关键词 | 妖气、霓虹、国潮、热闹、危险、贪婪、撤离 |
| 反例（避免） | 写实血腥、暗黑哥特、低饱和废土、日系萌系过度可爱 |
| 情绪曲线 | 基地=安心暖橙 → 进图=冷蓝紧张 → Boss=紫红压迫 → 撤离=金光贪婪 |

## 2. 配色系统（Color System）

### 2.1 主色 / 中性色

| 角色 | HEX | 用途 |
|---|---|---|
| 主色·妖青 | `#2BD4C4` | 玩家阵营、UI 主描边、安全区 |
| 主色·夜蓝 | `#1B2A4A` | 背景天空、地图底色 |
| 强调·霓金 | `#FFC24B` | 可带出资源、撤离点、稀有强化 |
| 危险·赤绯 | `#FF3B5C` | 敌弹、将损失提示、Boss 威胁 |
| 中性·墨黑 | `#0E1424` | 描边、对比底 |
| 中性·宣白 | `#F4EFE6` | 文字、高光 |

### 2.2 功能色（核心契约 —— 搜打撤专属）

| 功能 | 颜色 | 触发场景 | 视觉暗示 |
|---|---|---|---|
| 可带出（Loot-Safe） | 霓金 `#FFC24B` + 柔光脉冲 | 已拾取/可存入背包 | 资源边缘持续金色呼吸光，像被「封印」 |
| 将损失（At-Risk） | 赤绯 `#FF3B5C` + 裂纹描边 | 战斗中未撤离的带入资源 | 资源框红色裂纹随血量降低增多 |
| 安全（Safe-Zone） | 妖青 `#2BD4C4` | 基地 / 撤离成功 | 区域描边青色，无脉动 |
| 危险区（Danger） | 赤绯渐变 | Boss 弹幕、即死区 | 地面红色预警网格 |
| 强化等级 | 蓝→青→金→紫 | 肉鸽随机强化稀有度 | 色温随稀有度升高 |

### 2.3 敌我区分铁律

- **玩家永远偏冷/亮**（妖青描边 + 自身发光），**敌人永远偏暖/暗**（赤绯/紫描边）。
- 同屏敌我颜色不可落在同一色相区间；禁止红蓝对色盲不友好组合（见 accessibility）。

## 3. 光影（Lighting）

| 项 | 方向 |
|---|---|
| 光源 | 卡通硬光（1 主光 + 1 边缘光），无柔和全局光 |
| 阴影 | 程序化投影贴片（toon blob shadow），不写实 |
| 自发光 | 玩家/资源/强化用 emissive 表达「可带出」金光 |
| 氛围光 | 夜空霓虹辉光（bloom 克制，仅高光处） |
| 危险光 | 赤绯区域用体积雾 + 闪烁告警光 |

## 4. 造型语言（Form Language）

| 对象 | 造型原则 |
|---|---|
| 玩家机体 | 圆润几何 + 国潮纹样（祥云/雷纹）作贴花，辨识度靠**剪影** |
| 敌人 | 山海经妖物卡通化：九尾/鲲/烛龙幼体，夸张比例、可爱化威胁 |
| 环境 | 都市天际线 + 悬浮山海幻境；扁平色块 + 描边 |
| 一致性 | 所有物体统一 3px 墨黑描边（见 §9 技术规格） |

## 5. UI 视觉语言（UI Language）

| 项 | 规范 |
|---|---|
| 字体 | 标题：国潮美术字（描边+霓金）；正文：无衬线清晰字体 |

## 8. 动效原则（Motion）

| 原则 | 说明 |
|---|---|
| 可读性优先 | 弹幕移动必须轨迹清晰，禁用杂乱粒子遮挡 |
| 强反馈 | 命中/拾取/强化有「啪」的弹动 |
| 危险预告 | Boss 弹幕前 0.4s 红色预警线 |
| 克制 Bloom | 仅金光/高光发光，避免糊成一片 |
| 节奏 | 基地慢（0.6s），战斗快（0.12s 弹入） |

## 9. 技术规格（Technical Spec）

| 项 | 规范 |
|---|---|
| 渲染方向 | **Cel-Shading（卡通着色）+ 矢量描边**（推荐理由见下） |
| 分辨率 | 设计基准 1080p，支持 4K 输出；精灵 2x 超采样 |
| 图集 | 按场景/阵营分图集（player / enemy / ui / env），单图集 ≤ 2048² |
| 描边 | 后处理 Sobel 描边 或 顶点法线外扩，统一 3px |
| 着色器 | 自定义 Toon Ramp（3–4 阶）+ Fresnel 边缘光 + Emissive 金光 |
| 格式 | PNG（带透明）/ 图集 ASTC 或 ETC2（依引擎）；序列帧 WebP/序列 PNG |
| DCC | Photoshop / Aseprite（2D 矢量风）/ Blender（如需 3D 预渲染） |

### 9.1 卡通渲染方向推荐

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| Cel-Shading 实时 | 动态光照、可 3D、风格统一 | 工作量中、需定制着色器 | ✅ **采用**（主方案） |
| 扁平+描边 2D | 最快出量、最可控 | 缺乏体积感 | 用于 UI / 低耗设备降级 |
| 2D 矢量风 | 极致清晰、弹幕友好 | 与 3D 场景融合难 | 用于弹幕/图标子层 |

**理由**：shmup 需要极高可读性 + 动态光影表现妖气，Cel-Shading 兼顾两者；2D 矢量风作为弹幕/图标子层叠加，兼顾「国潮扁平」观感与实时性能。
