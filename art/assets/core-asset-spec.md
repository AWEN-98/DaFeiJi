# 首套核心资产规格（卡通）— Core Asset Spec v0

> 项目：shmup × 肉鸽 × 合成 × 搜打撤　|　美术基调：Cel-Shading 卡通
> 文档版本：v0（仅规格，不含成品美术）　|　评审标准：lean
> 命名规范根：`{faction}_{type}_{variant}_{state}`
> 例：`ply_fighter_a_idle` / `enm_yokai_fireboss_atk`

---

## 0. 通用规范

| 项 | 规范 |
|---|---|
| 画布基准 | 1080p 设计；精灵 2× 超采样后导出 |
| 描边 | 统一 3px 墨黑 `#0E1424` |
| 格式 | PNG-24（透明）/ 图集按引擎（Unity→ASTC, Godot→需确认） |
| DCC | Aseprite（像素矢量）/ Photoshop（绘制）/ Blender（3D 预渲染可选） |
| 帧率 | 战斗 60fps 动画；待机 24fps 循环 |
| 交付 | 分层 PSD + 导出 PNG + 图集 json |

## 1. 玩家飞机（2–3 款）

差异化靠**剪影 + 配色 + 辨识光**，不靠细节量。

| ID | 名称 | 剪影特征 | 主色 | 辨识度锚点 | 动画需求 |
|---|---|---|---|---|---|
| `ply_cruiser_a` | 巡航翼·青隼 | 后掠三角翼，细长 | 妖青 `#2BD4C4` | 翼尖青色光带，移动拖尾 | idle 浮空微抖 / move 倾转 / fire 翼尖喷光 |
| `ply_guardian_b` | 重装盾·玄龟 | 宽圆舰体，前置盾 | 墨蓝 `#1B2A4A`+金边 | 金色龟甲纹护盾展开 | idle 护盾呼吸 / hit 护盾闪 / fire 前炮 |
| `ply_dancer_c` | 灵巧碟·赤鸾 | 碟形旋翼，小巧 | 霓金 `#FFC24B` | 旋转尾迹花瓣状 | idle 自旋 / dash 残影 / fire 散射 |

> 参考图锚点（文字）：青隼=「国潮战机化祥禽，机翼如羽毛层叠」；玄龟=「战舰嵌玉甲，圆润厚重」；赤鸾=「圆盘如旋转团扇，拖金粉」。

## 3. 子弹 / 弹幕视觉

**强区分铁律：玩家弹与敌弹在形状、色相、明度三维度全部不同。**

| 类别 | 形状 | 颜色 | 明度 | 拖尾 | 备注 |
|---|---|---|---|---|---|
| 玩家弹 `prj_ply_*` | **圆 / 菱形** | 妖青→金渐变 | 高亮发光 | 短青拖尾 | 命中「啪」白闪 |
| 敌弹 `prj_enm_*` | **三角 / 锯齿** | 赤绯 `#FF3B5C` | 中暗 | 红雾拖尾 | 边缘 1px 白描边提可读性 |
| Boss 弹 `prj_boss_*` | 大锯齿+旋转 | 紫红+赤绯 | 中 | 强红雾 | 0.4s 前红色预警线 |
| 强化弹 `prj_buff_*` | 星型 | 霓金 | 高 | 金粉 | 肉鸽强化后变体 |

> 可访问性：色盲模式下去除红蓝对，敌弹改**橙黄锯齿**，玩家弹保持**青圆**（见 accessibility §3）。

## 6. 对 engineering 的资产管线假设

| 假设 | 说明 | 风险 |
|---|---|---|
| 引擎 | 暂定 Unity（ASTC 图集）；Godot 需二次确认 | 影响图集压缩格式 |
| 图集工具 | TexturePacker 导出 + 自定义 shader 注入 | 需约定 json 字段 |
| 描边 | 后处理 Sobel 统描边，非逐精灵手绘描边 | 边缘光一致性 |
| 帧动画 | 序列 PNG，非骨骼（机体小、骨骼收益低） | Boss 可考虑骨骼 |
| 金光 | Emissive + Bloom 后处理表达「可带出」 | 需 Bloom 可控开关 |
