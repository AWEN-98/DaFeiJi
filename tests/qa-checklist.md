# QA 测试清单（P4-QA）

> 角色：quality-lead（测试策略专家）｜平台：PC/Steam｜美术：卡通渲染
> 融合玩法：打飞机（弹幕 shmup）+ 肉鸽（随机强化）+ 合成（merge）+ 搜打撤（extraction）
> 核心循环：基地 → 选机体 → 选装备(带入) → 进地图 → 搜资源 → 战斗(弹幕/Boss) → 随机强化 → 合成 → 探索/撤离 → 带出 → 元进度；失败损失大部分带入资源
> 原则：lean、表格化、从垂直切片开始边做边测

---

## 0. 测试策略总览

| 项 | 内容 |
|---|---|
| 测试类型 | 功能清单测试 + 每冲刺冒烟 + 关键边界/崩溃 + 性能基线 |
| 起始点 | **垂直切片（Vertical Slice）**：单机体 + 单地图 + 1 个 Boss + 带入/撤离/损失最小闭环 |
| 最小可测路径 | 基地起局 → 带入1件装备 → 进图 → 击杀杂兵掉资源 → 随机强化1次 → 合成1次 → 撤离成功 → 带出资源入账 → 元进度+1 |
| 严重级定义 | **Blocker**：阻断核心闭环/必崩/数据丢失；**Major**：功能错误但可绕行；**Minor**：体验/数值/提示瑕疵 |
| 回归策略 | 每冲刺跑冒烟脚本；Blocker 全回归；Major 抽测；Meta 改动全回归 |

### 0.1 垂直切片最小可测路径（切入点）

```
[基地] 起局 ──▶ [选机体] 锁定1机 ──▶ [选装备] 勾选1件带入
   └─▶ [进地图] 单区域 ──▶ [搜资源] 拾取掉落
        └─▶ [战斗] 弹幕命中/受击 ──▶ [随机强化] 三选一生效
             └─▶ [合成] 两件同类合并 ──▶ [撤离点] 撤离成功
                  └─▶ [带出] 资源入账 ──▶ [元进度] 解锁+1
```

> 该路径贯通前，**只针对已落地模块做单元级清单验证**，不接受全量回归。

## 1. 核心循环（Core Loop）

| # | 用例 | 预期结果 | 严重级 |
|---|---|---|---|
| C1 | 完整闭环：基地→选机→带入→进图→搜→战→强化→合成→撤离→带出→元进度 | 全链路无阻断，最终资源/元进度正确入账 | Blocker |
| C2 | 任意节点中断重连（断线/崩溃后重进） | 状态可恢复或回退到安全节点，不重复发放/不丢非带入资源 | Blocker |
| C3 | 中途放弃对局（主动退出未撤离） | 按"失败"结算，带入资源按规则损失，对局清理无残留 | Major |
| C4 | 起局前带入校验 | 不存在/未拥有/已损坏的装备不可勾选带入 | Major |
| C5 | 单局内状态与元仓库隔离 | 单局拾取未撤离前，不影响基地仓库（防作弊/误操作） | Major |
| C6 | 同账号多开/双端并发 | 拒绝同局并发或隔离，不出现资源重复结算 | Major |

## 4. 搜打撤：带入 / 撤离 / 损失（Extraction）

| # | 用例 | 预期结果 | 严重级 |
|---|---|---|---|
| E1 | 带入装备登记 | 进入地图前带入清单与基地扣减一致 | Blocker |
| E2 | 撤离成功结算 | 局内拾取 + 带入装备全部带出，正确入账 | Blocker |
| E3 | 撤离失败/阵亡结算 | **仅损失大部分带入资源**（非全部），规则数值准确 | Blocker |
| E4 | 撤离点触发条件 | 满足条件下可撤离；不满足（如 Boss 未清/冷却中）明确不可 | Major |
| E5 | 撤离过程被击杀 | 判定为失败结算，不卡在"撤离中"状态 | Major |
| E6 | 带入资源损失比例边界 | 损失比例=0% 或 =100% 的极端配置被拦截或明确设计 | Major |
| E7 | 重复撤离/多次触发 | 一次撤离只结算一次，防重复带出刷资源 | Blocker |
| E8 | 局内掉落与带入资源区分 | 结算界面清晰区分"带入/拾取"，便于对账 | Minor |
