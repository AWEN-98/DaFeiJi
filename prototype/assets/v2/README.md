## 运行接入

基地背景、左侧功能导航、资源图标、任务简报、机体卡与结算状态已经接入 `prototype/index.html`。

HUD 框架和十二类特效已经接入 `prototype/game.js`。触发点包含开火、普通命中、暴击、受伤、敌人死亡、精英死亡、召唤、吸血、高价值目标、开箱、首领阶段和撤离。

第二批战术特效补充首领突进、危险地面、撤离中断、目标激活、终端破解、护盾破坏、宝库锁定与解锁、冲刺残影、低生命、路线箭头和探索扫描。基地新增任务地图页与完整风险情报。

第三批补充 8 个法器图标、4 个消耗品图标和 12 个符文图标，并接入军械库、熔炼台、战利品合成、符文三选一与战斗消耗品栏。出击流程新增任务加载画面，展示机体、层级、投放航道和阶段状态。军械库增加战力评估、当前装配标记与装配完成提示。

## 设计约束

安全信息使用青色与绿色，收益使用金色，普通危险使用红色，首领危险使用紫红色。颜色之外同时使用边框形状、图标和文字，满足色弱识别需求。

文字继续由 HTML 或 Canvas 实时绘制。位图与 SVG 保留无字版本，方便本地化、缩放和状态换色。

动效令牌包含悬停、按下、选中、锁定、警告、成功与减少动态效果模式。高频战斗特效设有 24 个实例上限。

## 生成记录

基地背景、核心特效、物品和符文采用内置图像生成模式。基地背景按 16 比 9 生成后裁切为 1920x1080 WebP。特效与符文先在纯绿色背景生成，再执行本地色键抠图并切分为 256x256 透明 PNG。物品源图自带透明通道，直接按网格切分并执行居中缩放。

UI 框架、图标与状态系统采用原生 SVG 和 CSS 制作，以保证缩放清晰度与编辑效率。
