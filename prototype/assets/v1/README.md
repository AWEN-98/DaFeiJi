# 空域撤离 v1 美术资产包

## 内容

- `atlases/`：四张带透明通道的完整图集。
- `sprites/player/`：三款玩家机体。
- `sprites/enemy/`：八类常规敌人、两名首领及三张扩展敌人图。
- `sprites/environment/`：掩体、隔断、秘库门、阵枢和宝箱。
- `sprites/effects/`：四类弹幕、两类战利品和两类撤离点。
- `sources/`：imagegen 生成的洋红底源图，供后续重新去底或精修。
- `manifest.json`：资产路径、用途和建议显示尺寸。

## 视觉规范

- 俯视角卡通硬光，三至四阶明暗。
- 墨色粗描边，强调小尺寸剪影可读性。
- 玩家使用妖青与冷光，敌人使用赤绯与紫色，精英和高价值目标使用霓金。
- 玩家弹为圆润菱形，敌弹为三角锯齿，脱色后仍能区分。

## 生成方式

使用 Codex 内置 imagegen 生成四张源图集，以纯洋红背景输出。本地使用 imagegen 技能的 `remove_chroma_key.py` 完成透明通道转换，随后按四列两行拆分。所有独立文件均通过 Alpha 通道和透明边角检查。

## 接入

浏览器原型会从 `assets/v1/sprites/` 预加载图片。图片尚未加载或加载失败时，Canvas 会继续绘制原有几何图形，保证游戏逻辑不受影响。
