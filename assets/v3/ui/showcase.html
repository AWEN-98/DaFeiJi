空域基地 UI 资产看图板

这是把你之前那几张大图按格子切出来的小图集合，共 87 张，外加 6 张大图。
每种零件都有几种"状态"（比如按钮的 正常 / 鼠标悬停 / 按下 / 禁用），方便以后做界面时直接换图，不会出现跳动。
请你点开看看：每张图是不是你想要的图案？名字对不对？哪里不对告诉我，我来改。

标签页（20 张）

机库/军械库/熔炼台/研究院/图鉴，每种有 正常/悬停/选中/禁用 四态

装备格（12 张）

武器/护甲/核心/弹药，每种有 正常/悬停/选中 三态

稀有度框（15 张）

普通/优秀/稀有/史诗/传说，每种有 边框/角饰/徽记 三种

按钮（12 张）

主/次/工具，每种有 正常/悬停/按下/禁用 四态

卡片（12 张）

难度/机体/商店/道具，每种有 正常/选中/锁定 三态

小图标（16 张）

按格子编号 00~33，共 16 个

特殊单体图（SPECIAL）

不需要切片的大尺寸特殊 UI：熔炼台主体、研究院科技卷轴等。

整张大图（ATLAS，6 张）

这是切图之前的原始大图，留底用。透明背景在网页里显示为深色。
