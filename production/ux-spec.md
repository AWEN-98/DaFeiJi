# UX 规范 UX Spec

> 文件：production/ux-spec.md ｜ 平台：PC/Steam ｜ 输入：键鼠 ｜ 关联：core-loop.md, 各系统 GDD

## 1. UX 流程总览

```
基地(机库/军械/研究院/熔炼/图鉴)
  └─[出击]→ 选机 ─→ 选装(带入) ─→ 选图(tier预览) ─→ 进图
进图: 战斗HUD ←→ 搜刮交互 ←→ 符文三选一 ←→ merge交互 ←→ 撤离交互
  └─[撤离读条]→ 结算屏 ─→ 基地
```

## 2. 信息架构与关键交互（键鼠）

### 2.1 基地 HUD
| 区域 | 内容 | 交互 |
|------|------|------|
| 顶栏 | 灵玉/声望/专属素材计数 | 悬停 tooltip |
| 左导航 | 机库/军械/研究院/熔炼/图鉴 | 点击切换 |
| 中央 | 当前功能面板 | 拖拽/点击 |
| 右下 | [出击] 按钮 | 点击→选机 |

### 2.2 选机 / 选装
- 选机：机体卡片网格，展示八维雷达图+槽位。**键**：1–4 快选；**鼠**：悬停看详情。
- 选装：左侧库存(按稀有点色)，右侧槽位拖拽装载。实时显示"在险总价值"(红字警示风险)。[带入] 按钮。

### 2.3 地图选择
- tier 卡片：显示 敌密度/风险区%/撤离点/推荐时长/历史胜率。
- 关键：**一目了然的风险-收益标签**，帮助决策(呼应 P1)。

### 2.4 战斗 HUD（核心，信息密度优先但不溢出）
| 位置 | 元素 | 说明 |
|------|------|------|
| 左上 | 生命/护盾条 | 醒目 |
| 左下 | 武器+模组图标(冷却环) |  |
| 右下 | 闪避技冷却 | 大按钮感 |
| 顶部中 | 灵能槽(符文图标) | 悬停看效果 |
| 右上 | 小地图(节点/撤离点) | 探索度 |
| 中下 | 战利品栏(快捷合成入口) | 点击展开 merge |
| 底部条 | 煞气(风险区)进度 | 警示色 |

### 2.5 撤离交互
- 抵达撤离点：出现 [撤离] 提示 + 读条环(2–4s)。**鼠**：站入圈内自动读条；**键**：E 确认。
- 读条中被打断：环破碎 + 红字"撤离中断"，可重试。
- 保底窗口期：全图开放撤离点，HUD 强提示。

### 2.6 符文三选一 / merge（不暂停战斗的轻交互）
- 符文：屏幕右侧弹出 3 卡，限时 8s 自动选最高权重；可手动点选。
- merge：战利品栏内拖拽同类合并，0.5s 动画锁，不暂停世界(考验间隙决策)。

## 3. 各界面的用户目标 / 挫败点 / 精简原则

| 界面 | 用户目标 | 常见挫败点 | 精简原则 |
|------|---------|-----------|---------|
| 基地 | 快速备装出击 | 面板深、找不到功能 | 默认聚焦[出击]，导航≤2级 |
| 选装 | 评估风险决策 | 词条看不懂、价值不清 | 色标稀有功、红字在险价值 |
| 战斗 | 生存+输出+决策 | HUD 信息过载 | 核心4元素固定位，次要折叠 |
| 撤离 | 安全带出 | 读条被打断焦虑 | 读条可重试+保底窗口 |
| 结算 | 看清得失 | 损失数字吓人 | 先显示"带回"，再展"损失"+保底说明 |

## 4. 通用精简原则（lean UX）
- 任何界面操作步骤 ≤ 3 次点击到达核心动作。
- tooltip 承载细节，主界面只留决策信息。
- 不可跳过内容仅限 5–10s 里程碑。
- 红/黄/绿 三色编码风险（呼应 P1 风险可见）。

## 5. 未决项
- 手柄支持是否列入 1.0（暂仅键鼠，手柄为延伸）。
- 战斗 HUD 是否提供"极简/标准/详尽"三档（建议提供，照顾不同玩家）。
- 小地图实时刷新频率与性能预算待技术确认。
