## 1. 垂直切片范围（最小可玩核心循环）

取 concept-doc **核心/MVP 垂直切片**子集，证明"搜打撤 + 弹幕 + 肉鸽 + 合成"组合成立：

| 内容 | 切片范围 | 排除（明确不做） |
|------|---------|----------------|
| 机体 | **1 机体**（基础移/射/闪避） | 多机体差异、变体 |
| 地图 | **1 张混合 PCG 小图**（SPAWN/LOOT/COMBAT/BOSS/EXFIL 各 1+） | 多图/风险档差异 |
| 敌人 | 基础杂兵 1–2 种 + **Boss 雏形 1**（单阶段弹幕） | 多阶段/精英 |
| 肉鸽 | 符文池 v1（约 **12 个**可叠加 buff） | 60+ 池、保底复杂化 |
| 合成 | 局内 **2合1** 基础（同类同级） | 连锁合成、3合1 |
| 搜打撤 | 带入 1 件 + 1 撤离点 + 损失模型（85%/70%） | 保险槽/保底复杂化（仅留接口） |
| 元进度 | 货币 + 解锁树雏形 + 库存 + 存档云同步 | 赛季/图鉴完整 |
| 表现 | 卡通渲染基础（SpriteAtlas + 2D 灯光占位） | 完美术术、特效 |

> 切片目标：**单局闭环可玩、可撤离、可元进度回填**（qa-checklist §0.1 最小可测路径）。

## 4. 对美术 / QA 的假设（Handoff 依赖）

### 4.1 对美术（art/）的假设
- **资产格式**：角色/敌人/Boss/地图模块 = **PNG（带透明）/TIFF 源**，经 Unity SpriteAtlas 打包；法线贴图可选（2D 灯光占位）。
- **切片资产清单**：1 机体（3 帧动画占位）、2 杂兵、1 Boss、1 地图模块集（房/廊/竞技场/撤离点）、子弹/拾取图标、UI 占位图。
- **卡通渲染**：URP 2D + 2D Lights；首批可先无光照占位，M3 后补。
- **锚点约定**：地图模块预制体需暴露 `SpawnAnchor`/`ExfilAnchor`/`EnemySpawnPoint` 空物体，供 MapGen 拼接（ADR-004）。

### 4.2 对 QA（qa-checklist / smoke-test-plan）的假设
- **测试框架对接**：QA 的 `smoke-test-plan.md` §3 直接消费本架构 `framework-scaffold.md` §3 的**事件/状态钩子表**（`OnExfilResult`/`OnMetaSettled` 等），不另起私有接口。
- **性能阈值**：在 Q4 未决前，QA 暂用 main-architecture §3 建议值（60fps 基线 / 30fps 最低）做断言。
- **最小可测路径**：以 qa-checklist §0.1 为准；M5 前仅做单元级清单，不做全量回归。
