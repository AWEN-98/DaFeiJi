# 关卡设计 · 悬圃·蚀空区块（Lead Level Designer 交付）

> 关联：map.md(锚点/节点) ｜ extraction.md(撤离/搜刮) ｜ core-loop.md(失败损失/保底) ｜ boss.md(多阶段) ｜ merge.md ｜ roguelike.md  
> 定位：tier 3 中高难度 raid，单局目标 8–12min，纯单机搜打撤。  
> 设计假设（若与你的预期不符，告诉我即可改）：① 本 raid 为「多区线性推进+1 隐藏分支」而非全开放；② 沿用现有四大 Boss 中的「饕餮(转) + 混沌(合)」作锚点；③ 玩家已熟悉基础射击/合成/撤离。

---

## 0. 当前问题诊断

原型现在是一块**同质竞技场**：随机刷怪 + 一个撤离点 + 一个宝箱。缺少三样东西，所以"枯燥、没记忆点"：

| 缺失          | 后果                       |
| ----------- | ------------------------ |
| **动态机制**    | 每局流程可预测，玩家无需动脑，只是"刷→撤"   |
| **起承转合**    | 没有教学/铺垫/颠覆/大考，紧张感恒定且无峰值  |
| **风险博弈的钩子** | 撤离随时可走，没有"此刻不走就亏/就死"的抉择点 |

本方案用 **1 个贯穿机制（相位潮汐）+ 1 个解谜式意外变数（吞噬借力）** 一次性补上这三样。

---

## 1. 核心机制与意外变数（Twist & Gimmick）

### 1.1 贯穿机制：相位潮汐 Phase Tide（全局状态机）

整个空域在 **鎏金相 / 余烬相** 之间自动循环（周期 40s）。这是本关的"心跳"，所有战术围绕它转。

| 相位            | 时长   | 环境                    | 敌人                          | 玩家                  | 经济                                            |
| ------------- | ---- | --------------------- | --------------------------- | ------------------- | --------------------------------------------- |
| **鎏金相 GOLD**  | 22s  | 暖金光、平静                | 弹速 -35% / 射速 -30%           | 护盾回充 +50% / 移速 +10% | 撤离点**蓄能**（不可撤离）；封印碑**锁**                      |
| **余烬相 EMBER** | 18s  | 余烬橙光、煞气弥漫             | 弹速 +20% / 射速 +25% / 移速 +15% | 无增益                 | 全局掉率 **×2**；封印碑**可破**；撤离点**开放窗口(前 8s 可发起读条)** |
| 切换过渡          | 1.5s | 全屏扫光 + 字幕"相位翻转" + 提示音 | —                           | —                   | —                                             |

**玩家操控权（防被动）：** 地图预埋 **相位柱 ×2–3**，玩家触碰可**强制下一次相位提前切换**（CD 60s）。这让玩家能主动"把撤离窗口调到我想要的时刻"，而不是纯看天吃饭。

> 落地提示（对程序）：在 `update()` 里跑 `phaseTimer`；`Mission.phase ∈ {GOLD, EMBER}`；撤离点 `Exfil.open = (phase==EMBER && openWindowRemaining>0)`；封印碑 `Vault.sealBroken = (phase==EMBER && playerHits)`。

### 1.2 意外变数：吞噬借力 Devour-Borrow（利用敌人能力解谜）

饕餮的「吞噬」本应是**威胁**（把你拉向中央巨口致死）。在 Zone 3 我们把它反转成**工具**：

- **开门**：磁锁秘库的闸门核心在灵壁另一侧。玩家站到对齐位引诱饕餮发动吞噬 → 拉力把核心隔着灵壁拽出 → 闸门开启（隐藏分支入口）。
- **吸宝**：Zone 3 地面散落大量战利品。余烬相站在「引力裂隙」上，饕餮一次吞噬会把**全厅松散战利品瞬间吸到你脚下**——一次收尾，效率爆炸。

> 这是"利用敌人能力解谜"的教科书式应用：Boss 的能力从"要躲的东西"变成"要利用的东西"。

## 2. 任天堂式「起承转合」节奏

### 起 · Zone 1 悬圃外垣（安全引入，~1.5min）

- **目标**：让玩家在零压力下次秒懂"相位潮汐"。
- **内容**：1 根相位柱（带高亮教学圈）+ 散落箱 ×3（白/绿）+ 1 座封印碑（故意在鎏金相锁住，字幕提示"余烬相方可破封"）。
- **引导**：玩家打封印碑发现打不动 → 相位翻转到余烬 → 一击即破 → 立刻理解机制。无 Boss、无精英。
- **心流**：纯正反馈，建立"相位=机会"的第一直觉。

### 承 · Zone 2 灵脉回廊（综合运用，~2.5min）

- **目标**：把相位时机 + 新机关「灵脉节点」+ 合成 编织成常规挑战。
- **新机关**：**灵脉节点**（可被击毁的发光桩）。击毁一个会引爆连锁 AoE，清掉周围小怪——教玩家"用环境打敌人"。
- **内容**：混合敌（游隼突进型 + 玄龟炮台型）；封印碑 ×2（余烬可破）；灵脉节点 ×4 串联；拾取 2 件同款武器触发**局内合成**教学。
- **分支（低风险 R/R）**：可选「悬空裂隙」抄近路跳到 Zone 3，但内部**时间坍缩**（移速 +40%，战利品每秒衰减 15%）——只在残血/赶时间时划算。

### 转 · Zone 3 噬渊广场（规则颠覆，~3min）

- **目标**：给玩家"逆向思维"的惊喜与压力。
- **颠覆点 1**：撤离点**只在余烬相开放窗口（前 8s）**，逼你在最危险的时候做最关键的决策。
- **颠覆点 2**：饕餮作为**环境 Boss（非必杀）**&#x76D8;踞广场，持续吞噬拉拽。常规思路是"躲开它"；本区奖励"**利用它**"（开门 / 吸宝，见 §1.2）。
- **内容**：异兽巢 ×1（紫/橙，高风险厚利）+ 散落战利品铺地 + 引力裂隙 ×1（Aha 触发点）。
- **记忆点**：玩家第一次"故意站到吞噬路径上"的反直觉操作。

### 合 · Zone 4 虚空王座（高潮大考，~3–4min）

- **目标**：综合考验 + 关底 Boss 互动。
- **Boss**：混沌（终局）。**弹幕模式与相位绑定**：鎏金相 → 环形弹幕（易读、可走位）；余烬相 → 螺旋弹幕（难、但掉率 ×2）。玩家需用相位柱**主动切回鎏金**来制造读弹窗口。
- **大考结构**：混沌 3 阶段（护甲阶段 ×2 + 狂暴）。破最后阶段 → 王座内**最终撤离点**开启（此时必为余烬开窗，呼应全关主题）。
- **终极奖励**：区块核心（高价值）+ 传说装备，必须在王座撤离点带出。
- **保底**：局末段（超时/连续受创）全图强制开撤离窗（core-loop §3.3），杜绝"必死撤离"。

## 3. 心流与决策点（Risk vs. Reward）

### 3.1 隐藏分支 · 磁锁秘库（高回报，硬核向）

- **入口**：Zone 3 用吞噬借力拉开磁锁闸门（见 §1.2）。
- **产出**：保底 1 传说装备 + 区块核心（整局最高价值）。
- **代价（二选一）**：① 让饕餮吞噬命中你一次（约 25% 生命 chip 伤）；② 主动**弃掉 1 件已装备**（被闸门吸收换开锁）。
- **设计意图**：给"我来都来了"的硬核玩家一个明确的贪婪理由，同时用真实代价拦住普通玩家无脑冲。

### 3.2 低风险分支 · 悬空裂隙（见 §2 承）

- 跳过 Zone 2 后半段战斗，但战利品持续衰减。是"保命/赶时间"的逃生阀，不是致富路。

### 3.3 Aha! Moment · 相位借力

- **触发**：Zone 3 余烬相，玩家首次站上引力裂隙、被饕餮吞噬、发现全厅战利品一次性归位。
- **为什么是 Aha**：玩家此前一直把吞噬当威胁，此刻突然意识到"这是我的吸尘器"。同一机制，认知翻转。
- **强化**：首次触发给成就「以彼之道」，并在图鉴记录，形成传播点。

### 4.3 数值 / 时间节奏建议

**相位潮汐**

- 周期 40s = 鎏金 22s + 余烬 18s；切换过渡 1.5s（不计入，纯演出）。
- 相位柱主动触发 CD 60s，每次把当前相位剩余时间压缩到 ≤3s 即翻。

**撤离窗口（extraction.md 对齐）**

- 余烬相开放窗口 **前 8s** 可发起读条；读条 **3s**（原 GDD 2–4s 取中）；读条中被击中打断（保留保底窗）。
- 王座最终撤离点：混沌破最后阶段瞬间强制进入余烬开窗 8s。

**Boss（boss.md 对齐，多阶段 + 弱点窗口）**

- 饕餮（环境）：不击杀也可撤离；吞噬 CD 6s，拉拽力随距离衰减；引力裂隙使其吸程 ×2。
- 混沌（关底）：3 阶段，每阶段转换暴露核心 2–3s（弱点 ×3）；P3 狂暴但同步开放保底撤离。

**搜刮产出（extraction.md 对齐，余烬 ×2）**

| 点    | 常规期望                        | 余烬相期望 |
| ---- | --------------------------- | ----- |
| 散落箱  | 灵材2–5 / 灵玉5–15              | ×2    |
| 封印碑  | 灵材8–15 / 灵玉20–40 / 符文1–2    | ×2    |
| 异兽巢  | 灵材20–40 / 灵玉60–120          | ×2    |
| 磁锁秘库 | 传说×1 + 区块核心（保底）             | —     |
| 混沌掉落 | 橙武×1 + 混沌核(首杀免疫损失) + 灵玉200+ | ×2    |

**单局时长基线（core-loop §4 对齐）**

- 起 1.5 / 承 2.5 / 转 3 / 合 3–4 = 搜战 10–11min；加基地准备 + 撤离结算 ≈ 11–13min（tier 3 推荐 12min，达标）。
