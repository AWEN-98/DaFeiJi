# 裂隙 / 黑洞系统 · 设计规范

> **设计哲学（一句话）**：裂隙是「赌徒的岔路」——玩家在安全路线之外看见一个未知入口，可以选择无视，也可以选择压上当前战利品换一次搏命机会。

---

## 一、入口生成（永远在「非必经之路」）

| 规则项 | 设计值 | 说明 |
|------|------|------|
| 单图数量 | **1–2 个** | 小图 1 个，大图/多房间图 2 个；超过 2 个会稀释「稀有抉择」感 |
| 生成位置 | **非必经之路** | 仅出现在：死胡同房间、地图边缘角落、需绕路/穿障碍才能到达的支线房间。**绝不**出现在主路径、撤离点连线、或 Boss 房所在区域 |
| 判定标准 | 路径标记 | 地图生成时给每个房间打「是否必经」标签（必经 = 连接出生点与撤离点/Boss 的最短路径上的房间）；裂隙只从「非必经」房间池里抽签 |
| 视觉标识 | 紫黑漩涡 | 紫色与黑色交错的动态漩涡特效（缓慢旋转 + 边缘粒子吸积），常驻发光，夜晚/雾区也清晰可见 |
| 小地图图标 | **❓ 紫色** | 小地图上以紫色 ❓ 标记，与主地图的撤离点（A/B/C 字母）、宝箱（◆/★/✦）图标明显区分 |
| 靠近提示 | 文字浮标 | 玩家进入漩涡 220 像素范围内，HUD 顶部淡入文字「未知裂隙 · 触碰可进入」 |
| Boss 房禁用 | 强制排除 | 生成阶段显式跳过 Boss 房及其附属竞技区域，避免与 Boss 战叠加形成不可控难度 |

---

## 二、进入规则（主动选择 · 明确告知风险）

| 步骤 | 行为 | 玩家感知 |
|------|------|---------|
| 1. 触碰入口 | 玩家机体接触漩涡边缘（半径约 40 像素） | 漩涡短暂「咬合」动画（缩一下再张开） |
| 2. 弹确认框 | 暂停世界，弹出确认浮层：「进入裂隙？内部情况未知，风险自担。」含 **[确认]** / **[取消]** 两按钮 | 明确告知「未知 + 风险自担」，非强制 |
| 3. 冻结战利品 | 进入瞬间，当前**战利品栏被暂时冻结**：带进去的装备/丹药/灵玉砂被锁定为「暂存」，内部拾取不与外部混算 | 视觉上战利品栏置灰 + 挂「冻结中」标签 |
| 4. 传送 | 角色淡出，载入独立小地图（与当前主地图完全隔离，敌人/地形独立） | 屏幕过渡特效（吸入漩涡） |

**冻结的语义**（策划澄清）：冻结 = 你带进去的东西在裂隙期间不参与任何「丢失」判定，出来即原样归还。冻结**不是**把它们押进赌池——真正的赌注在下面「平衡说明」一节单独解释。

---

## 三、内部房间设计（每次进入随机触发其一）

进入后从下方三型抽签，**与玩家当前战力/层数无关**，纯随机保证「未知」感：

| 类型 | 概率 | 房间形态 | 内容 | 收益 | 风险 |
|------|:---:|------|------|------|------|
| **宝库房** | 40% | 空旷圆形厅，中央 1 个秘宝箱，无敌人、无陷阱 | 触碰即开，必出 **1 件紫或橙**装备（紫 70% / 橙 30%） | 纯奖励，零战斗 | 无 |
| **竞技房** | 40% | 封闭矩形竞技场，四壁封锁（无门） | 分 **3 波**刷敌，波间隔 3 秒；全清后房间尽头掉落 **2 蓝 + 1 紫** | 稳定高价值战利品 | 房间封锁，**不清完无法离开**；期间受伤/阵亡风险真实存在 |
| **陷阱房** | 20% | 空房间，四角有可搜刮的「阴影裂隙」，但中央无物 | 进入 **3 秒后**触发全屏缓慢毒雾（每秒 **−8 HP**，持续 **15 秒**）；房间某角落藏 **1 件隐藏紫装** | 无直接掉落实体，但角落紫装价值可观 | 必须在毒雾中撑 15 秒并找到隐藏物；找不到=白挨打 |

### 三类房间的细节补充

- **宝库房**：秘宝箱开启动画与主线「秘宝（✦）」一致（金光 + 粒子爆），保证玩家认知统一。
- **竞技房**：
  - 波次配置——第 1 波 2 只普通，第 2 波 3 只（含 1 精英），第 3 波 3 只（含 1 远程）；难度随主地图层数轻微上浮。
  - 封锁机制——四壁在入场时闭合，最后一波敌人血量归零的瞬间墙体裂开、尽头传送门亮起。
  - 掉落位置——2 蓝 + 1 紫 直接掉在房间中央地面，拾取即入（冻结外的）裂隙收益池。
- **陷阱房**：
  - 毒雾为「缓降」而非瞬杀：3 秒预警期（屏幕边缘泛绿 + 倒计时「毒雾 3…2…1」），之后全屏淡绿蒙版 + 每跳 −8 HP 飘字。
  - 隐藏紫装位于随机一角（非正中），需玩家主动探索；找到后自动标记在小地图（裂隙内专用迷你地图）。
  - 毒雾结束（15 秒到）即视为「房间完成」，传送门亮起。

## 四、退出规则（收益豁免「未撤离即丢」）

| 环节 | 规则 |
|------|------|
| 房间完成判定 | 宝库房=开箱；竞技房=全清；陷阱房=毒雾计时结束（或拾取隐藏物后计时结束均可） |
| 传送门开启 | 完成后房间尽头自动亮起紫色漩涡传送门（与入口同美术） |
| 返回位置 | 触碰传送门 → 回到**主地图原裂隙入口处**（非出生点）；战利品栏冻结解除，带进去的物品原样归还 |
| **收益豁免** | 裂隙内获得的所有战利品**直接进入战利品栏，且不受主线「未撤离即丢」规则约束**——即本局最终若阵亡，裂隙内捡到的物品以 **50% 概率保留至局外**（作为「搏命」保底），其余 50% 随局销毁 |
| 阵亡于裂隙内 | 见「联动规则」第 1 条（返回主图入口、HP 30%、裂隙关闭） |

> **豁免的边界**：豁免仅覆盖「裂隙内拾取物」。玩家进入前冻结的外部战利品，仍遵守主线撤离规则（成功 100% / 阵亡按主线损失比例）。两者在结算时分别计账，互不影响。

## 五、UI 反馈（让抉择可见、可读）

| 场景 | UI 表现 |
|------|--------|
| **进入前确认框** | 显示当前战利品栏**总价值估值**（按稀有度折算灵玉当量，如「当前押注估值 ≈ 320 灵玉」）+ 提示「你要压上这些东西冒险」+ [确认]/[取消] |
| **内部房间顶部标签** | 常驻类型条，例如：「⚔️ 竞技房 · 3 波敌人」「🎁 宝库房 · 安全」「☠️ 陷阱房 · 毒雾 15s」 |
| **陷阱房毒雾** | 屏幕正中大号倒计时「毒雾 12s」，边缘绿色脉冲随剩余时间加深 |
| **裂隙内小地图** | 独立迷你地图（仅显示当前房间 + 传送门 + 隐藏物标记），与主图小地图切换，避免迷路 |
| **退出结算** | 返回主图时弹一行飘字「裂隙收益已并入战利品（阵亡保底 50%）」，强化「搏命有底」认知 |
| **冻结状态** | 主界面战利品栏挂「❄ 冻结中」角标，提示玩家这些物品暂时不可用于合成/熔炼，出来后恢复 |

## 六、与现有系统联动

| 已有机制 | 联动规则 |
|---------|---------|
| **裂隙内阵亡** | 角色返回**主地图入口位置**（非裂隙入口），HP 回复至 **30%**，该裂隙**本局永久关闭**（入口漩涡消散，小地图 ❓ 消失）；已冻结的外部战利品原样归还 |
| **风系符文（≥1 枚）** | 陷阱房毒雾伤害 **减半**（−4 HP/s）；视觉上毒雾呈青色被风卷散，呼应「风系驱散」语义 |
| **火系符文（≥1 枚）** | 竞技房敌人 **额外 +20% 移速**（火系引燃敌意，更凶），但**掉落品质整体提升一档**（蓝→紫、紫→橙概率上移），高风险高回报 |
| **元素反应** | 裂隙内战斗正常触发主线元素反应（如持有的火/雷系与敌机护盾互动），不另设独立反应表 |
| **Boss 房** | 生成阶段强制排除，Boss 战期间绝不出现裂隙入口 |
| **搜刮点/宝箱体系** | 宝库房内的秘宝箱复用主线「秘宝（✦）」开启表现与命名，保证认知一致；不重复占用主线宝箱配额 |
| **撤离惊动（见前文规则）** | 裂隙为独立子地图，其内部不触发主线撤离惊动；但**裂隙内停留会消耗主图时间**——若主图撤离点限时开放窗口在裂隙期间关闭，玩家出来即错过，可能损失全部外部战利品（这是「真实赌注」的核心，见下） |

## 七、平衡与一致性说明（策划备注）

### 7.1 真实的「赌注」在哪里

冻结机制保护了玩家带进去的物品，因此本系统的真风险**不在物品抵押**，而在三处：

1. **时间窗口**：主图撤离点有「开放—关闭」限时循环。沉迷裂隙可能回来发现窗口已关，外部战利品按主线规则损失。这是最主要的隐性赌注。
2. **生命值**：竞技房/陷阱房会真实掉血，裂隙内阵亡虽保底回归 30% HP，但位置不利 + 裂隙关闭，可能连环暴毙。
3. **机会成本**：走裂隙 = 放弃一条更稳的搜刮/撤离路线。

→ 因此「压上当前战利品」更多是**叙事与心理层面**的压迫感（确认框的估值提示），机制上用「时间 + 生命」做真实约束，二者结合才构成可信的高赌注。

### 7.2 可选增强：压注模式（完全实现「赌徒的岔路」）

若希望赌性更硬，可额外提供**主动压注**（默认关闭，由策划开关控制）：

- 进入前可选择「押上外部战利品」：押注后裂隙内收益 **×2**，但若裂隙内阵亡，**押注物品 100% 销毁**（不复原、不保底）。
- 不押注则维持 §二/§四 的冻结+50% 保底安全线。
- 此模式把确认框从「风险提示」升级为「风险分级」，彻底兑现设计哲学。

| 参数 | 值 | 可调说明 |
|------|:---:|---------|
| 单图裂隙数 | 1–2 | 随地图尺寸 |
| 入口距主路径 | ≥ 必须绕路 | 死胡同/边缘/支线 |
| 宝库房概率 | 40% | 安全甜头 |
| 竞技房概率 | 40% | 主风险房 |
| 陷阱房概率 | 20% | 稀有高风险 |

## 收尾 · 裂隙系统五步流程

> 玩家在主图探索时，**偶然**于非必经角落瞥见一道紫黑漩涡（小地图 ❓）→
> **① 看见**（未知入口，可无视也可靠近）→
> **② 抉择**（触碰弹出确认框，显示当前战利品估值，「压上这些东西冒险？」确认/取消）→
> **③ 进入**（战利品冻结，传送至独立子地图，随机落入宝库房/竞技房/陷阱房之一）→
> **④ 搏命**（安全房白捡 / 竞技房清三波锁门 / 陷阱房撑毒雾找隐藏物，收益直接入袋且豁免「未撤离即丢」）→
> **⑤ 归来**（房间完成亮起传送门，返回主图原入口解冻战利品；阵亡则保底 50% 留存、裂隙关闭）——整条链路把「搜刮—赌博—撤离」咬合成一条**可见原因、可预判结果、可自主进退**的风险决策链，而非被动挨打。
