# 空域基地 UI 重设计 · ChatGPT 生成需求文档

> **用途**：把本文件整体丢给 ChatGPT（o1 / 4o / GPT-4o-image 等），让它一次性生成可落地的视觉资产 + HTML/CSS/JS 代码。
> **项目**：《空域撤离》浏览器 MVP（打飞机 × 肉鸽 × 合成 × 搜打撤）
> **当前状态**：已有 v2 基地 UI，但风格与项目圣经冲突（霓虹卡通 vs 黑暗奇幻油画），需要整体重设计。

---

## 一、项目风格圣经（必须严格遵守）

### 色板
| 名称 | 色值 | 用途 |
|---|---|---|
| 基底黑 | `#0E0B08` | 背景、暗部、边框 |
| 鎏金 | `#C9A24B` | 高亮、边光、品牌、选中、按钮 |
| 余烬橙 | `#C8642A` | 火焰、爆炸、危险、警示 |
| 米白 | `#E8DCC4` | 文字、高光核心 |
| 羊皮纸米 | `#E8DCC4` | 说明文字、次级信息 |
| 青翠 | `#5FBFA3` | 玩家/友方/治疗（少用，仅点缀） |
| 煞红 | `#B03A3A` | 敌人/Boss/危险 |
| 幽紫 | `#8A6FB8` | 史诗稀有度/秘宝 |
| 橙金 | `#D98A3D` | 传说稀有度 |

### 风格关键词
`dark fantasy, Chinese mythological creature, Shan Hai Jing inspired, thick oil paint and impasto texture, visible brushstrokes, gilt gold rim light, ornate, cinematic, NO neon, NO cel-shading, NO cartoon, NO flat vector, NO anime`

### 整体氛围
- **不要霓虹感**：禁用荧光青、高饱和电光蓝、赛博网格、矢量发光。
- **要油画厚涂**：可见笔触、颜料堆叠感、暗部沉下去、鎏金边光勾勒轮廓。
- **要中式志怪**：山海经异兽、符文、青铜器纹样、残卷、墨迹。
- **要电影感**：强烈明暗对比，局部暖金高光，大面积深褐/墨黑。

## 二、现有基地 UI 结构（保留功能，重做视觉）

基地是游戏的「大厅」，包含 5 个 Tab + 底部出击按钮：

| Tab | 中文名 | 当前功能 |
|---|---|---|
| hangar | 机库 | 选择难度层级、选择出击机体、永久强化商店、当前目标提示 |
| arsenal | 军械库 | 把战利品（法器）装备到 4 槽：武器 / 护甲 / 核心 / 弹药 |
| forge | 熔炼台 | 2 件同槽合成升稀、3 件同槽升级+随机词条、回收换灵玉 |
| lab | 研究院 | 用灵玉解锁永久被动升级 |
| codex | 图鉴 | 显示已遭遇敌人、战利品、套装、传说武器说明 |

顶部显示 3 个资源：
- **灵玉**（货币）
- **法器**（当前仓库战利品数量）
- **层**（已解锁最高难度 1/3）

底部：
- **出击 ▶** 按钮（进入战斗）
- **怎么玩** 按钮（打开教学）

## 三、重设计核心方向

### 1. 布局骨架（必须兼容现有 HTML 结构）
```
┌─────────────────────────────────────────────────┐
│  空域基地            [灵玉] [法器] [层 1/3]      │  <- 品牌头 + 资源条
│  SKY BUREAU 07                                   │
├─────────────────────────────────────────────────┤
│  [机库] [军械库] [熔炼台] [研究院] [图鉴]        │  <- Tab 导航
├─────────────────────────────────────────────────┤
│                                                  │
│              各 Tab 内容区                        │  <- 可滚动内容
│                                                  │
├─────────────────────────────────────────────────┤
│           [       出 击 ▶       ] [怎么玩]      │  <- 底部操作区
└─────────────────────────────────────────────────┘
```

### 2. 视觉层级要求
- **背景**：机库 Tab 使用厚重油画风格的机库场景（可保留 assets/v2/base/base_hub_hangar_1920x1080.webp 构图，但重绘为油画+鎏金风格）。
- **面板**：深褐/墨黑半透明面板（rgba(14,11,8,0.88)），边缘用鎏金细线 + 轻微内发光，角落有青铜纹饰。
- **文字**：标题用鎏金渐变 + 轻微辉光；正文用羊皮纸米白；禁用色用暗红灰。
- **选中态**：不是霓虹绿发光，而是鎏金描边 + 暖光内投影 + 细微粒子光尘。
- **按钮**：出击按钮用鎏金渐变，按下时像青铜机关咬合，有鎏金碎屑粒子。

### 3. 各 Tab 视觉要求

#### 机库 Tab
- **难度层级卡**：3 张卡（第 1 层·入门 / 第 2 层·进阶 / 第 3 层·深渊），像悬挂的青铜符文牌。未解锁的牌呈锈蚀青铜质感，锁链缠绕。
- **机体选择卡**：3 架机体（青隼/玄龟/赤鸾），用立绘框 + 油画风格小图 + 青铜铭牌显示属性。选中时边框鎏金发光，背景有淡金色墨迹。
- **永久强化商店**：6 个升级项，像卷轴残片或青铜齿轮，等级用鎏金刻度条显示。
- **目标提示**：顶部一句当前目标，像残卷批注，左侧有朱砂印章图标。

#### 军械库 Tab
- **4 个装备槽**：武器 / 护甲 / 核心 / 弹药，做成青铜器凹槽形态。
  - 空槽：凹槽内幽暗，边缘有符文暗纹。
  - 有装备：显示装备缩略图标 + 名称 + 稀有度色边 + 核心词条 2 行。
- **仓库列表**：按槽位分组，每组有青铜标牌。条目像古卷残片，稀有度越高越华丽（白=素绢 / 绿=青铜铭 / 蓝=靛染帛 / 紫=秘纹锦 / 橙=鎏金诏）。
- **操作按钮**：装载/卸下/回收，做成小型青铜按钮，hover 时轻微浮起。

#### 熔炼台 Tab
- **合成台**：中央一个青铜熔炉/八卦盘，周围摆放材料位。
- **结果预览**：熔炉上方浮现合成结果剪影，稀有度色用鎏金/幽紫/橙金。
- **快捷操作**：「2合1升稀」「3合1升级」「回收」三个按钮像青铜机关拉杆。

#### 研究院 Tab
- **科技树/卷轴**：竖向卷轴展开，每个升级项像一枚青铜印章或玉简。
- **已解锁**：印章鎏金亮起；未解锁：印章蒙尘，显示所需灵玉。

#### 图鉴 Tab
- **分类导航**：敌人 / 战利品 / 套装 / 传说武器，做成朱砂标签。
- **条目卡**：已解锁显示油画立绘/图标 + 说明；未解锁显示残破剪影 + "???"。

## 五、前端代码要求

### 必须保留的现有结构
不要改 `index.html` 里基地区域的 DOM ID：
- `#base`（整个基地遮罩）
- `.base-panel`（主面板）
- `.base-head` / `.base-brand` / `h1` / `.base-sub`
- `.res-bar` / `#resJade` / `#resArsenal` / `#resProgress`
- `.tabs` / `.tab`（data-tab 属性必须保留：hangar/arsenal/forge/lab/codex）
- `#tab-hangar` / `#tab-arsenal` / `#tab-forge` / `#tab-lab` / `#tab-codex`
- `#tierRow` / `#aircraftList` / `#shopList` / `#loadoutPreview`
- `#arsenalList` / `#forgeList` / `#researchList` / `#codexBox`
- `#startBtn` / `#helpBtn`

### 代码输出要求
ChatGPT 需要输出：
1. **完整的 `<style>` 块**（直接替换 `index.html` 中基地相关 CSS，不要改游戏内 HUD CSS）。
2. **不需要改 HTML 结构**，只做 CSS + 背景图引用。
3. **如果涉及图片引用**，路径统一使用 `assets/v3/ui/` 和 `assets/v3/base/`（预留 v3 目录，避免覆盖 v2）。
4. **响应式**：必须兼容桌面 1920×1080 和移动端横屏 720×360，文字不能重叠，按钮可点击。
5. **性能**：禁止用视频背景、禁止大量 box-shadow 层叠、动画必须走 transform/opacity。
