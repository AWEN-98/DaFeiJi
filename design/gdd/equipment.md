# 系统 GDD：装备系统 Equipment

> 八节结构 ｜ 关联：core-loop.md(带入风险), merge.md, roguelike.md

## 1. 概述
武器与模组是玩家带入局的核心风险资产，也是 build 的主要构成。装备分"带入(库存)"与"局内获取"两类，稀有度决定强度与损失代价。

## 2. 目标
- 提供清晰的武器/模组梯度与风格差异。
- 带入即风险（呼应 P1），稀缺高稀装备驱动风险博弈。
- 与 merge/roguelike 形成 combo 深度。

## 3. 核心机制
- **武器**：主火力来源，含类型（散射/直射/追踪/范围）、基础 DPS、弹道特性。
- **模组**：被动/主动效果（增伤、吸血、闪避强化、灵能扩展等），入模组槽。
- **带入 vs 局内**：
  - 带入：从基地库存装载，进图即 at-risk（失败按 core-loop §3 损失）。
  - 局内获取：地图搜刮/击杀掉落，未撤离则丢失；撤离后入库。
- **稀有度**：白(普通)/绿(精良)/蓝(稀有)/紫(史诗)/橙(传说)，5 档。
  - 高稀 → 高属性 + 额外词条；高稀带入损失代价更高（风险博弈）。

| 稀有度 | 属性倍率 | 额外词条 | 带入风险权重 |
|-------|---------|---------|------------|
| 白 | 1.0 | 0 | 低 |
| 绿 | 1.2 | 1 | 低 |
| 蓝 | 1.5 | 1–2 | 中 |
| 紫 | 2.0 | 2–3 | 高 |
| 橙 | 3.0 | 3–4 | 极高 |

## 4. 数值模型
- 武器 DPS 基准随 rarity：`DPS = base × rarity_mult × (1 + 词条和)`。
- 模组效果以 % 或固定值叠加到机体八维。
- 词条池与符文池部分重合（如"灵能+20%"），使 merge/roguelike 可协同。

## 5. 流程
基地选装 → 装载槽位(校验机体槽数) → 进图生效 → 局内可替换拾取装备（替换后原装备入战利品栏，按撤离结算）。

## 6. 依赖系统
- aircraft.md（槽位）｜ merge.md（同类合成升稀）｜ roguelike.md（符文强化装备）｜ economy.md（掉落/损失经济）｜ extraction.md（搜刮点产出）

## 7. 风险
- 高稀装备过度保值时玩家不敢带入 → 需保底与保险槽（core-loop §3.2）。
- 词条随机导致"垃圾橙装">"好蓝装"认知混乱 → 词条权重透明化（UX 展示）。

## 8. 验收标准
- 5 档稀有度数值梯度平滑，无档位倒挂。
- 带入装备在失败结算中正确应用损失比例。
- 装备词条在 HUD/tooltip 完整可读（ux-spec.md）。
