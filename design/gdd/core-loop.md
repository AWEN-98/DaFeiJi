## 1. 核心循环状态机

```
        ┌─────────────────────────────────────────────────────┐
        │                  基地 BASE（局外元进度）               │
        │  解锁树 / 货币 / 装备库存 / 机体库 / 图鉴              │
        └───────────────┬─────────────────────────────────────┘
                        │ 选择出击
                        ▼
        ┌───────────────────────────┐
        │   选机体 SELECT AIRCRAFT   │  受解锁树约束
        └───────────┬───────────────┘
                    ▼
        ┌───────────────────────────┐
        │  选装备 LOADOUT（带入）     │  从库存选武器/模组；消耗即风险
        └───────────┬───────────────┘
                    ▼
        ┌───────────────────────────┐
        │   选地图 SELECT MAP         │  难度梯度/风险区/撤离点预览
        └───────────┬───────────────┘
                    ▼
        ┌─────────────────────────────────────────────────────┐
        │                  进图 IN-MISSION（局内）               │
        │                                                       │
        │  搜 SCRAVENGE ──► 战 COMBAT(弹幕/Boss)                 │
        │       │                  │                            │
        │       │                  ▼                            │
        │       │          随机强化 ROGUELIKE(符文)              │
        │       │                  │                            │
        │       └──────────► 合成 MERGE(局内即时)               │
        │                          │                            │
        │                          ▼                            │
        │              探索/再搜  ◄──(循环直到决定撤离)           │
        │                          │                            │
        │                          ▼                            │
        │              撤离 EXIT？──── 否 ──► 回到 搜/战         │
        │                  │ 是                                 │
        │                  ▼                                    │
        │          抵达撤离点 EXFIL POINT                        │
        └───────────┬───────────────────────────────────────────┘
                    │
        ┌───────────┴────────────┐
        │ 结算 RESOLVE            │
        │ 成功带出 vs 阵亡/超时    │
        └───────┬────────┬───────┘
                │        │
         成功带出     失败(阵亡/未撤离)
                │        │
                ▼        ▼
        ┌────────────┐ ┌──────────────────────────┐
        │ 资源入库    │ │ 损失大部分带入(见§3)       │
        │ 元进度回填  │ │ 保底返还(见§3例外)         │
        └─────┬──────┘ └────────────┬─────────────┘
              │                     │
              └─────────┬───────────┘
                        ▼
                  回到 基地 BASE
```

## 2. 局内 ↔ 局外 数据与状态衔接

| 数据 | 局内状态 | 局外状态 | 衔接规则 |
|------|---------|---------|---------|
| **带入装备** | 标记为"在险"(at-risk) | 库存中可用 | 进图瞬间锁定为在险；成功撤离→回库存；失败→按§3损失 |
| **局内拾取资源** | 暂存于"战利品栏" | 不入库存 | 仅当抵达撤离点才结算入库；阵亡即清空 |
| **符文(肉鸽强化)** | 临时 buff，局内生效 | 不保留 | 离局清空；仅"符文图鉴"记录已见 |
| **合成产物** | 局内装备/模组 | 若带入物则随装备规则 | 局内合成的非带入物，随撤离结算入库 |
| **货币(灵玉等)** | 局内可拾取 | 库存累加 | 同资源规则，撤离才入账 |
| **统计/成长** | 局内累计击杀/探索% | 图鉴/成就/赛季 | 离局即写，不受影响惩罚 |

**状态字段约定（引擎层参考）**
- `LoadoutItem.state ∈ {IDLE, AT_RISK, LOST, RETURNED}`
- `Mission.state ∈ {SCRAVENGE, COMBAT, BUFF, MERGE, EXFIL, RESOLVED}`
- `Exfil.result ∈ {SUCCESS, DEATH, TIMEOUT}`

## 3. 失败惩罚模型（损失大部分带入资源）

### 3.1 阈值与比例

| 情形 | 带入物处理 | 局内拾取处理 | 货币 |
|------|-----------|------------|------|
| **成功撤离 SUCCESS** | 100% 带回 | 100% 入库 | 100% 入账 |
| **阵亡 DEATH** | 损失 **85%** | 全部丢失 | 丢失 100% 局内拾取 |
| **超时未撤离 TIMEOUT** | 损失 **85%** | 全部丢失 | 同上 |
| **主动放弃(弃局)** | 损失 **70%**（比阵亡少，鼓励止损） | 全部丢失 | 同上 |

> "大部分"定义为 **≥70%**，核心局阵亡/超时取 85% 以强化风险。

### 3.2 例外（不损失）

| 例外项 | 规则 |
|--------|------|
| **保险槽 Insured slot** | 每个机体 1 个"已投保"栏位，阵亡必返还（消耗保费/冷却） |
| **剧情/教程装备** | 前 3 局教学装备免疫损失 |
| **Boss 首杀奖励** | 首杀掉落的专属素材必带回，不计入损失 |
| **保底返还** | 若玩家连续 2 局全损，第 3 局系统赠送 1 件随机蓝装带入并免疫损失（防劝退） |

### 3.3 保底规则（防负循环）

| 触发 | 保底 |
|------|------|
| 连续全损 ≥ 2 局 | 第 3 局：免费保险装 + 符文池权重提升（更易出高 rarity） |
| 库存装备 ≤ 1 件 | 基地自动发放"求生包"（1 白装武器+1 白装模组），不消耗货币 |
| 货币 < 最低出击成本 | 发放"低保灵玉"，仅够 1 次基础出击 |

## 4. 单局节奏基线（P3 约束）

| 阶段 | 目标时长 | 备注 |
|------|---------|------|
| 基地准备 | 30–90s | 选机/装/图 |
| 局内搜+战 | 6–12 min | 核心 |
| 撤离决策+结算 | 30–60s | 含保底提示 |
| **合计** | **8–15 min** | 超 25 min 视为失衡，需切分地图 |

## 5. 未决项
- 保险槽的"保费"来源（货币 vs 时间冷却）待经济系统定稿。
- 主动弃局的 70% 损失是否区分"已拾取未撤离"需与 economy.md 对齐。
- 保底"求生包"是否影响成就统计（建议不计入白嫖率）。
