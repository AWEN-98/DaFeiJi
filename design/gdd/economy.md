# 系统 GDD：经济系统 Economy

> 八节结构 ｜ 关联：extraction.md(资源), core-loop.md(失败损失), metaprogression.md(货币)

## 1. 概述
经济系统是风险博弈的数学底座：平衡带入代价、失败损失、产出价值与通胀回收，确保长线可持续（支柱 P1/P4）。

## 2. 目标
- 失败惩罚数学清晰（损失大部分带入，core-loop §3）。
- 控制通胀（产出有回收口）。
- 货币分层，防止单资源通吃。

## 3. 核心机制
- **资源/货币**：灵材(合成) / 灵玉(通用货币) / 声望(解锁) / 专属素材(Boss) / 符文残片(池)。
- **价值锚定**：以"标准出击成本"为基准单位(SCU)。1 次基础出击 ≈ 1 白装(耗灵玉 20)。
- **失败损失数学**：带入资产按 core-loop §3 比例(阵亡85%/弃局70%)损失，损失计入"沉没"，不返还（例外见保底）。
- **通胀控制**：
  - 熔炼费(merge 基地)消耗灵玉。
  - 高稀装备带入需"投保费"(保险槽)。
  - 重复装备自动折价回收为灵材。

## 4. 数值模型
- **期望净收益（单局，中等 tier2）**：
  - 产出期望 ≈ 灵玉 60 + 灵材 12。
  - 出击成本 ≈ 灵玉 20（白装折旧）。
  - 净期望 ≈ +40 灵玉/局（正反馈，但含 15% 全损风险）。
- **损失期望值**：`E[loss] = P_death×0.85×带入值`。
  - 若带入值=100 灵玉等价，P_death=0.2 → E[loss]=17，仍低于净收益 → 系统正向但惩罚可见。
- **回收率**：每局约 10% 产出经熔炼费/折价回收，抑制指数通胀。

## 5. 流程
进图(扣出击成本)→搜刮(产出暂存)→撤离(入库)→基地消费(解锁/熔炼)→再出击。

## 6. 依赖系统
- extraction.md（产出/损失）｜ core-loop.md（损失模型/保底）｜ metaprogression.md（货币消耗）｜ merge.md（熔炼费）｜ equipment.md（投保）

## 7. 风险
- 高稀保值致玩家不敢带入 → 保底/保险槽缓解，监控带入率（目标 60%+ 玩家愿带蓝+）。
- 通胀失控(灵玉溢出) → 动态回收（熔炼费随持有量递增）。
- 低保机制被刷 → 低保仅发基础装，不发现金。

## 8. 验收标准
- 单局 E[net] 为正但带可见风险（playtest 经济曲线验证）。
- 失败结算正确应用损失比例 + 保底（联 core-loop）。
- 投放 100 局模拟无通胀发散（数值脚本验证）。
