# 系统 GDD：元进度 / 成长系统 Metaprogression

> 八节结构 ｜ 关联：core-loop.md(局外回填), economy.md, aircraft.md(解锁)

## 1. 概述
基地是局外成长的载体，将单局收益转化为持久解锁（支柱 P4）。强调"技巧可补偿肝度"，避免纯付费墙。

## 2. 目标
- 提供可见、可积累的"我变强了"反馈。
- 解锁树覆盖机体/装备蓝图/符文图鉴/基地功能。
- 回填循环：单局→资源→解锁→更强单局。

## 3. 核心机制
- **基地功能**：机库(机体) / 军械库(装备库存) / 熔炼台(merge) / 研究院(解锁树) / 图鉴。
- **货币**：灵玉(通用) / 声望(解锁进度) / 专属素材(Boss)。
- **解锁树**：分 4 支（机体线/装备线/符文线/基地线），节点消耗声望+灵玉。
- **解锁成本**：机体 i 需 `声望 = 50×i²`；装备蓝图逐级递增。
- **回填**：单局带出资源→声望/灵玉→解锁→下一局更强。

## 4. 数值模型
- 声望获取：每局 `基础(10) + 探索%×20 + 击杀×2 + 撤离奖励(30)`。
- 单机体解锁约需 5–8 局（不含保底）。
- 图鉴：记录已见装备/符文/Boss，纯收藏不赋能（防必须全收集）。

## 5. 流程
基地→消费资源解锁→装载出战→带出资源→回基地→继续解锁。

## 6. 依赖系统
- aircraft.md（机体解锁）｜ equipment.md（蓝图）｜ roguelike.md（符文图鉴）｜ economy.md（货币）｜ merge.md（熔炼台）

## 7. 风险
- 解锁树过深致长草期 → 设里程碑奖励（每 3 节点给保底橙）。
- 肝度墙劝退 → 技巧补偿（高难通关给双倍声望）。
- 付费 skip 破坏公平 → 仅售卖皮肤/装饰，不卖数值（待发行策略确认）。

## 8. 验收标准
- 解锁树在 40h 内可推进至全解锁（不含纯刷）。
- 保底机制防负循环（联 core-loop §3.3）。
- 基地各功能在 UX 中可操作(ux-spec.md)。
